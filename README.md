# Deep Space Ark AI

深空方舟是一套面向竞赛演示的交互式自主任务决策系统。

它以可拖拽的 3D 轨道数字孪生为核心，演示太阳风暴事件、事故链推演、多智能体协作、救援方案比较和人类授权执行。

## 演示能力

- 3D 木星轨道场景与空间站模型
- 五阶段危机演示时间线
- 多智能体联合决策与事故链推演
- 三套救援方案的生存率和能耗比较
- 自动演示、手动选择与执行交互

## 本地运行

```bash
npm install
npm run dev
```
